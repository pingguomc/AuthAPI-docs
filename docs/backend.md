# 后端专门要求

这里存放对后端的特别要求

## 命令系统

后端需要一个简单的命令系统，从终端读取命令并执行。

目前需要终端执行的命令包括：

* `/reload` 输入此命令，会热重载全部配置文件。
* `/admin <用户ID>` 将此用户系统角色设为 `admin`，并为其创建唯一的后台账户，**级别为 `super_admin`**（超级管理）。
* `/SQL <语句>` 可用于直接执行 SQL 语句。

> **审计要求**：终端相关命令（`/reload`、`/admin`、`/SQL`）均属敏感操作，操作内容、执行结果与操作时间须一律计入审计日志（后台审计，记录操作人、命令全文与返回结果），不得绕过审计。终端物理可达即视为拥有最高权限，操作务必留痕。
